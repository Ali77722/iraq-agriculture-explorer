# Iraq Agriculture Explorer

**المستكشف الزراعي للعراق** — منصة تعليمية عربية تفاعلية لاستكشاف المحاصيل والزراعة في العراق، مستندة أساساً إلى فصل الزراعة في كتاب الاجتماعيات للصف الثالث المتوسط العراقي.

## تشغيل الموقع

- افتح `index.html` مباشرة في متصفح حديث. ملفات البيانات والجغرافيا محلية، ولا يحتاج الموقع إلى خادم خلفي أو قاعدة بيانات أو مفتاح API.
- الإنترنت مطلوب فقط لفتح روابط المصادر؛ بقية التجارب تعمل دون اتصال.
- تقدم الاختبار والإنجازات وبعض إعدادات التجربة تُحفظ محلياً في المتصفح. لا تُرسل هذه البيانات إلى خادم.

## محتوى المنصة

- خريطة SVG تفاعلية لحدود المحافظات الثماني عشرة وفق طبقة geoBoundaries التي تمثل سنة 2022، مع إشارات الكتاب وأرقام تقرير الحنطة والشعير الرسمي لعام 2025 حسب المحافظة (ضمن تغطية المسح فقط).
- موسوعة قابلة للبحث والتصفية تضم الحبوب والمحاصيل الزيتية والخضروات والفواكه والنخيل والمحاصيل الصناعية والعلفية.
- محاكاة نوعية مبسطة، ومختبر قرارات يعرض حقائق المحاصيل غير المدعومة بمؤشر رقمي، ولقطات تاريخية من الكتاب (2018–2019)، وملخص مؤشرات 2025 وتوقعات FAO لموسم 2026، وقاموس واختبار ورحلة محصول وإنجازات.
- الواجهة عربية RTL ومتجاوبة؛ لا توجد مكتبات JavaScript أو خدمات مدفوعة.

## ملاحظة حدود مهمة

خريطة المصدر المفتوح تعرض 18 وحدة إدارية ويمثل إصدارها سنة 2022. استُحدثت محافظة حلبجة بوصفها المحافظة التاسعة عشرة في 2025. لم نعثر ضمن مصدر الهندسة الموثق المضمّن على شكل محدث لحدودها، لذلك لا نرسم لها حدوداً تخمينية. تعرض المنصة هذا القيد داخل الخريطة، وتصف الأرقام الزراعية بأنها تاريخية.

## تحديث المحتوى

كل محصول في `data/content.js` يذكر الموسم والظروف فقط عندما يسندها الفصل. الحقول غير المسندة تُخفى في التفاصيل. الأرقام الإضافية تتضمن السنة والنطاق والمصدر؛ وتُعرض البيانات الجغرافية المفقودة كغير متاحة ضمن المسح، لا كصفر. قبل تحديث `data/governorates.js`، راجع تاريخ صلاحية طبقة الحدود والترخيص والأسماء والعدد، ثم حدّث تنبيه الخريطة وملاحظات المصدر.

## المصادر والتراخيص

- كتاب الاجتماعيات للصف الثالث المتوسط العراقي، فصل «الزراعة»، الصفحات المطبوعة 50–57. ملخص المحتوى وسياسة الأرقام في [ملاحظات المصادر](docs/SOURCES.md).
- [geoBoundaries Iraq ADM1 API](https://www.geoboundaries.org/api/current/gbOpen/IRQ/ADM1/): 18 وحدة، الهندسة تمثل 2022، ترخيص CC0 1.0. بيانات الحدود مضمّنة محلياً لتعمل الصفحة دون اتصال.
- [وزارة العدل العراقية](https://www.moj.gov.iq/view.9251/) و[قوانين مجلس النواب](https://archive5.parliament.iq/law/?entry=1585): مراجع قانونية لاستحداث محافظة حلبجة عام 2025.
- [الجهاز المركزي للإحصاء العراقي — تقارير الإنتاج الزراعي](https://www.cosit.gov.iq/index.php/ar/agri-stat/veg-prod) و[المؤشرات الزراعية](https://www.cosit.gov.iq/ar/agri-ind): إحصاءات رسمية مع نطاق التغطية موضح في الصفحة.
- [FAO GIEWS — موجز العراق](https://www.fao.org/giews/countrybrief/country.jsp?code=IRQ): توقعات الموسم الزراعي لعام 2026.
- لا توجد صور خارجية أو خطوط أو مكتبات خارجية مطلوبة للتشغيل.
