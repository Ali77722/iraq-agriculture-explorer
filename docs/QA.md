# التحقق والجودة

## ما يغطيه التحقق

- بنية HTML وRTL ومراجع الملفات المحلية.
- سلامة بناء JavaScript وبيانات الموسوعة والخريطة.
- وجود الأسماء والأنواع والسنوات التاريخية اللازمة، وعدم ربط محصول بمحافظة غير معروفة في بيانات التطبيق.
- تصميم الهاتف وتقليل الحركة.
- الخريطة والاختيارات والتكبير والتحريك والبطاقات.
- المحاكاة ومختبر القرارات والاختبار والقاموس والإنجازات والحفظ المحلي.
- التحميل من `index.html` مباشرة، ثم نشر GitHub Pages والتحقق من الرابط المنشور.

## فحص المطور

يتطلب تشغيل الفحص وجود Node.js حديث في بيئة التطوير، ولا يحتاج الموقع نفسه إلى Node:

```sh
node tests/verify_data.mjs
```

### نتيجة الفحص الساكن في بيئة التطوير

- نجح فحص HTML وRTL والمراجع الداخلية والملفات المحلية والأيقونة SVG وتوازن كتل CSS.
- نجح فحص صياغة JavaScript وبيانات المحتوى: 25 محصولاً، 18 مضلعاً جغرافياً، الأسماء العربية، الإسناد الجغرافي، سنوات 2018/2019، والأنشطة التعليمية.
- جرى فتح الموقع الحي والتحقق من عرض الواجهة العربية ووجود الأقسام والبيانات على GitHub Pages.

## قائمة التحقق اليدوية

- [x] الخريطة: تحميل المحافظات بالعربية، واختيار الأنبار أظهر إسناد السمسم كما يورده الفصل.
- [x] موسوعة المحاصيل: ظهرت 25 بطاقة؛ فتح تفاصيل القمح عرض الموسم والماء والتربة والمناطق وإحالة صفحات المصدر.
- [x] المحاكاة: تحليل الرز عرض قراءة نوعية مع بيان أنها لا تتنبأ بالإنتاج.
- [x] المختبر: إجابة سؤال الرز أظهرت تفسيراً وإحالة الصفحة واحتسبت النقطة.
- [x] الاختبار: الإجابة الصحيحة أظهرت التغذية الراجعة ورفعت النتيجة إلى 1.
- [x] الحفظ المحلي: بعد إعادة تحميل الموقع بقيت نتيجة الاختبار والإنجازات الأربعة.
- [x] بعد النشر: رابط HTTPS فتح، وأقسام الصفحة والبيانات ظهرت على GitHub Pages.
- [ ] التحقق اليدوي الكامل من فلاتر الموسوعة، جميع سيناريوهات المحاكاة والاختبار، القاموس والرحلة، عرض الهاتف والسحب باللمس.

## تنبيه دقة جغرافي

البيانات الجغرافية المضمّنة تمثل 2022، وتضم 18 وحدة. بعد استحداث حلبجة في 2025 أصبحت محافظة تاسعة عشرة؛ لا تظهر حدودها الجديدة في طبقة المصدر. تعرض الواجهة هذا القيد بجوار الخريطة. لا تعتبر خريطة 2022 خريطة مكتملة للتقسيم الإداري الحالي.
