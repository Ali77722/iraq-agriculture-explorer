# خطة التنفيذ وسجل التقدم

## مبادئ العمل

- تنفيذ مرحلة واحدة ثم مراجعة ناتجها قبل بدء التالية.
- توثيق المصدر والسنة مع كل معلومة أو رقم؛ بيانات الكتاب التاريخية لا توصف بأنها حديثة.
- لا تُعرض حدود المحافظات أو روابط محصول بمحافظة كحقائق قبل التحقق من مصدرها.
- محاكاة المزرعة تعليمية مبسطة وليست تنبؤاً بالإنتاج.
- الحفاظ على JavaScript وHTML/CSS خفيفة وقابلة للتشغيل محلياً وملائمة لـ GitHub Pages.
- Git هو سجل التغييرات؛ مع كل مرحلة مستقرة تُنشأ أيضاً نسخة ZIP منفصلة.

## المرحلة الأولى: التخطيط والتأسيس

### المكتمل في هذه المرحلة

- فُحص مجلد العمل: مستودع Git موجود مسبقاً لكنه فارغ ولا يحتوي ملفات مشروع أو commits؛ لم تُستبدل محتويات قائمة.
- قُرئ فصل الزراعة من الكتاب المرفق، الصفحات المطبوعة 50–57. ملخصه ومراجعته في `docs/SOURCES.md`.
- اختيرت بنية ملفات صغيرة بلا إطار عمل أو خادم خلفي.
- حُدد geoBoundaries ADM1 كمرشح للحدود، مع إبقاء دمجه مشروطاً بالتحقق.
- وُضع اتجاه بصري: واجهة عربية RTL، أخضر نباتي وألوان ماء/تربة هادئة، بطاقات واضحة وحركة محدودة، مع أولوية القراءة على الزخرفة.

### تحقق الإغلاق

- اكتمل سجل المصادر وحدود الادعاءات قبل بناء الواجهة.
- اجتازت ملفات التأسيس فحص الملفات المطلوبة وتغطية المراحل والسنة/الإسناد في ملاحظات المصدر، كما اجتاز `git diff --check`.
- حُفظ commit ووسم ونسخة ZIP مستقلة لهذه المرحلة.

## قرارات البنية الأولية

- `index.html`: نقطة الدخول، مع أقسام دلالية وإعداد RTL.
- `css/styles.css`: التصميم المتجاوب ومتغيرات الألوان والمسافات.
- `js/app.js`: تفاعلات الواجهة؛ تقسيم إضافي فقط إذا فرضه الحجم.
- `data/crops.json`: سجل منظم للمحاصيل مع المصدر والسنة ودرجة الإسناد.
- `data/governorates.geojson`: نسخة محلية ثابتة من مصدر الحدود بعد تدقيقها، لتفادي اعتماد الخريطة على الشبكة وقت التشغيل.
- `assets/images/`: صور مرخصة/موثقة أو رسومات أصلية؛ بدائل نصية عند تعذر الموارد.
- `.github/workflows/pages.yml`: إعداد نشر GitHub Pages في مرحلة النشر.
